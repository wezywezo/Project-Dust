# Project Dust

> **A modern open-source platform for Fallout 2d20.**

Project Dust est un projet open source dont l'objectif est de concevoir un moteur moderne, modulaire et entièrement documenté destiné à accompagner les campagnes du jeu de rôle **Fallout 2d20**.

Le projet est développé de manière incrémentale selon une architecture documentée, des décisions d'architecture (ADR) et un processus de développement organisé en sprints.

---

# Vision

Project Dust poursuit plusieurs objectifs :

- Concevoir un moteur robuste et évolutif pour Fallout 2d20.
- Développer une architecture modulaire et facilement extensible.
- Documenter chaque décision importante afin de constituer une mémoire durable du projet.
- Adopter un processus de développement transparent et reproductible.
- Favoriser une collaboration efficace entre développeurs humains et intelligence artificielle.

---

# Philosophie

Project Dust considère la documentation comme une composante essentielle du développement.

Chaque décision importante est documentée avant son implémentation afin de garantir :

- une architecture cohérente ;
- une maintenance facilitée ;
- une évolution maîtrisée du projet.

> **La connaissance guide l'exécution. L'exécution produit le logiciel.**

# Développement

Le développement suit un processus incrémental documenté.

```text
Ideas
   │
   ▼
Roadmap
   │
   ▼
Sprint
   │
   ▼
Code
```

Chaque fonctionnalité suit ce cycle afin de conserver une architecture cohérente, une documentation à jour et une traçabilité complète des décisions.
